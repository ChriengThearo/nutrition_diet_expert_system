Frequently asked questions

What databases does Laravel Cloud support?

Laravel Cloud supports managed MySQL and Postgres databases, as well as compatible external providers.

Can I bring my own database?

Yes. You can connect an existing database while keeping deployments and application infrastructure managed by Cloud.

How does autoscaling work on Laravel Cloud?

Cloud monitors application demand and adjusts replicas automatically, including scaling down when an application is idle.

Can I try Laravel Cloud for free?

Start building with free usage credit and upgrade as your application grows.
